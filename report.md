# Отчет по лабораторной работе №2

## Задание
Написать программу на языке C/C++ для перемножения двух матриц. (С использованием OMP)
- Исходные данные: файл(ы) содержащие значения исходных матриц.
- Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи.
- Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).

## Реализация
1. Генерация матриц:
Программа создает квадратные матрицы размером от 10×10 до 100×100 с шагом 10
Элементы матриц заполняются случайными числами от 0.0 до 10.0
2. Сохранение данных:
Каждая пара матриц сохраняется в файлы matrix_A_[size].txt и matrix_B_[size].txt
Результаты перемножения сохраняются в result_[size].txt
3. Измерение производительности:
Для каждого размера матрицы измеряется время перемножения
4. Верификация:
Каждый результат проверяется с помощью библиотеки Eigen
## Использование OpenMP:
Для распараллеливания умножения матриц были использованы:
- `#pragma omp for` для распределения итераций внешнего цикла по потокам.
- Использовано 4 и 8 потоков для сравнения эффективности.

## Вывод
Добавление OpenMP позволило ускорить вычисления. Добавление количества потоков не сильно увеличивает производительность из за небольших объемов матриц. Гиперпоточность не удваивает вычислительную мощность — она просто позволяет лучше использовать простаивающие ресурсы ядра.
На вычислительно интенсивной задаче, вроде перемножения матриц (особенно целочисленного!), все физические ALU (арифметические блоки) уже максимально загружены.
