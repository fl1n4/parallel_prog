# Отчет по лабораторной работе №3

## Задание
Написать программу на языке C/C++ для перемножения двух матриц. (С использованием MPI)
- Исходные данные: файл(ы) содержащие значения исходных матриц.
- Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи.
- Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).

## Реализация
1. Генерация матриц:
Программа создает квадратные матрицы размером от 10×10 до 100×100 с шагом 10
Элементы матриц заполняются случайными числами от 0.0 до 10.0
2. Сохранение данных:
Каждая пара матриц сохраняется в файлы matrix_A_[size].txt и matrix_B_[size].txt
Результаты перемножения сохраняются в result_[size].txt
3. Измерение производительности:
Для каждого размера матрицы измеряется время перемножения
4. Верификация:
Каждый результат проверяется с помощью библиотеки Eigen
## Использование MPI:
1. Инициализация MPI:
- Вызов MPI_Init, получение ранга процесса MPI_Comm_rank и общего числа процессов MPI_Comm_size.
2. Генерация данных:
- Процесс с рангом 0 генерирует две случайные матрицы A и B.
- Матрица B рассылается всем процессам с помощью MPI_Bcast.
3. Разделение работы:
- Матрица A делится по строкам на части, которые распределяются между процессами с помощью MPI_Scatterv.
- Каждый процесс вычисляет свою часть результата (локальное умножение своей части матрицы A на общую матрицу B).
4. Сбор результатов:
- Части итоговой матрицы C собираются обратно на процесс 0 с помощью MPI_Gatherv.
5. Верификация и сохранение результата:
- На процессе 0 выполняется проверка результата с помощью библиотеки Eigen.
- Результаты записываются в файл.
6. Завершение MPI:
- Вызов MPI_Finalize.
### Использовано 4 и 8 процессов для сравнения эффективности.

## Вывод
Добавление MPI позволило ускорить вычисления. Добавление количества процессов не сильно увеличивает производительность из за небольших объемов матриц. MPI эффективен при больших задачах и при необходимости распределённого вычисления. MPI даёт хороший прирост производительности на больших размерах матриц (500×500 и больше). Оверхед на передачу данных между процессами существенный на малых задачах.
