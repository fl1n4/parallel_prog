# Отчет по лабораторной работе №4

## Задание
Написать программу на языке C/C++ для перемножения двух матриц. (С использованием CUDA)
- Исходные данные: файл(ы) содержащие значения исходных матриц.
- Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи.
- Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).

## Реализация
1. Генерация матриц:
Программа создает квадратные матрицы размером от 10×10 до 100×100 с шагом 10
Элементы матриц заполняются случайными числами от 0.0 до 10.0
2. Сохранение данных:
Каждая пара матриц сохраняется в файлы matrix_A_[size].txt и matrix_B_[size].txt
Результаты перемножения сохраняются в result_[size].txt
3. Измерение производительности:
Для каждого размера матрицы измеряется время перемножения
4. Верификация:
Каждый результат проверяется с помощью библиотеки Eigen
## Использование CUDA:
1. `__global__ void matrixMultiplyKernel(const int* A, const int* B, int* C, int N)`
- ядро (kernel) выполняется на GPU. Каждый поток CUDA вычисляет один элемент результирующей матрицы C[i][j]. Расчёт значения C[i][j] производится по стандартной формуле умножения матриц.
2. С помощью вызовов cudaMalloc выделяется память под матрицы на видеокарте.
- `cudaMalloc(&d_A, bytes); cudaMalloc(&d_B, bytes); cudaMalloc(&d_C, bytes);`
3. Перед вычислениями данные с CPU копируются на GPU.
- `cudaMemcpy(d_A, flatA.data(), bytes, cudaMemcpyHostToDevice); cudaMemcpy(d_B, flatB.data(), bytes, cudaMemcpyHostToDevice);`
- После завершения вычислений результат возвращается обратно в оперативную память.
- `cudaMemcpy(flatC.data(), d_C, bytes, cudaMemcpyDeviceToHost);`
4. Ядро CUDA запускается с помощью конфигурации сетки и блоков.
5. После запуска ядра вызывается: `cudaDeviceSynchronize()`;
- Это гарантирует, что все вычисления на GPU завершены перед тем, как данные будут использоваться на CPU.
